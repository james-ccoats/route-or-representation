# Experiment log

Dated entries, newest at the bottom. Copy the template for each entry. Record
the exact command and config so results can be reproduced.

## Template

```
## YYYY-MM-DD: <short title>

**Phase:** <0-4>
**Config / command:** `uv run python scripts/XX_name.py --config configs/...`
**Git commit:** <hash>   **Seed:** <n>   **Model revision:** <hash>

**What ran:** <what was run and any deviations from the plan>

**Result:** <numbers, tables, links to files in results/ and figures/>

**Interpretation:** <what this does and does not show; caveats>

**Next step:** <what to do next and why>
```
